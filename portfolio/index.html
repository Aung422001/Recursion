The brief

It started as English ↔ Burmese.

The plan was a single course: an English↔Myanmar learning app to show full-stack ability for junior developer roles across Southeast Asia. Multiple language pairs were explicitly out of scope for v1.

Halfway through, that changed on purpose. The people I wanted to reach speak Thai, Vietnamese, Malay, Hindi and Arabic as often as English, and a second pair would have exposed every assumption the first one hid. So I generalised the whole model: ten languages, every ordered pair, and each language's writing system taught as content.

The hard part was never adding languages. It was making ten scripts, two writing directions and ninety courses cost the same to maintain as one.

Course matrix

Ten languages make ninety courses.

Writing "thank you" ninety times, and fixing it ninety times, does not scale. Each concept holds one meaning in all ten languages, and a course is that set read through two language codes. An eleventh language is one more key per concept, and it opens twenty new courses at once.

Decisions

Choices that shaped the build

Each of these came from a concrete problem, and each is covered by tests.

Content

Exercises are generated, not stored

Lessons are built on request from a PRNG seeded on lesson, source and target. Storing them would mean 1,440 near-identical documents. Because generation is deterministic, the server can rebuild a lesson to grade an answer without remembering what it sent.

Integrity

The server grades every answer

Lessons reach the browser with correctAnswer stripped, so answers never appear in the page source. Every graded answer is also the natural moment to update the review schedule.

Learning

Progress belongs to the language

Knowing こんにちは is the same knowledge whether you reached Japanese from English or from Malay. The schedule is keyed on concept and language; lesson completions stay per course.

Input

Only ask for typing someone can do

Few laptops have a Burmese keyboard. Typed answers flip to whichever side uses a Latin script, and when neither does (Thai from Japanese) the lesson leans on multiple choice and matching instead.

Scripts

Every script declared, every font chosen

Each language carries its script, writing direction and romanization needs. Without the right font and dir, Burmese and Thai render as boxes and Arabic runs backwards. No flag emoji: Windows has no glyphs for them, and a language is not a country.

Time

Streaks roll over at your midnight

Someone studying at 11pm in Yangon should not lose a streak to a server clock. The client reports its UTC offset, and read paths zero out a streak that has already expired so the dashboard never shows one you have lost.

Spaced repetition

A missed word comes back in ten minutes, not tomorrow.

Review runs on SM-2, written as a pure function with an injectable clock so every edge case is tested without a database. Textbook SM-2 sends a failed item to a one-day interval. Losing a word and not seeing it for a day is how learners forget it, so a lapse schedules a retry in the same sitting and resets the ladder.

Architecture

An npm-workspaces monorepo in three parts

Client and server share one dependency-free constants module: the language catalogue, exercise types, SM-2 grades and XP values. The browser shows the same numbers the server will award.

Auth flow

register / login ─→ access token 15 min, held in memory only └→ refresh token 30 days, httpOnly cookie any 401 ─→ one shared POST /api/auth/refresh ─→ retry the original request logout everywhere ─→ bump refreshTokenVersion, no blocklist needed

Concurrent requests share a single in-flight refresh instead of racing, so a token expiring mid-lesson is invisible to the learner.

What's next

Known gaps, stated plainly

  1. ShippedMonorepo, auth, data model, lesson flow, SM-2 review, streaks, XP and dashboard across all 90 courses.
  2. Week 8Deploy the server and client, with MongoDB Atlas in production, and link a live demo here.
  3. ContentA native-speaker pass on every language. Politeness in Japanese and Korean verbs and gendered forms in Arabic are where the demo vocabulary is most likely to be off.
  4. InterfaceThe UI and unit titles are English only. A learner studying Thai from Japanese still reads English buttons.
  5. AudioThe default voice uses an unofficial endpoint. Production should point TTS_PROVIDER at a paid service, which is a single case in one switch.
